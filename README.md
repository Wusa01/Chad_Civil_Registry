🇹🇩 Chad Civil Registry

نظام السجل المدني التشادي – Digital Civil Registration System

نظام رقمي لإدارة وتنظيم خدمات السجل المدني، مبني باستخدام Python وFlask، ويهدف إلى تسهيل إدارة بيانات المواطنين والوقائع المدنية والوثائق المرتبطة بها، من خلال منصة رقمية تدعم العربية والفرنسية.

يدعم النظام إدارة المواليد والزواج والوفاة والطلاق، وطلبات المواطنين، وإصدار الوثائق بصيغة PDF، والتحقق منها باستخدام QR Code، بالإضافة إلى الأرشفة الرقمية والتقارير والنسخ الاحتياطي وإدارة المستخدمين والصلاحيات.

ومن أبرز مميزات النسخة الحالية إمكانية تشغيل النظام على Windows مباشرة، دون الحاجة إلى تشغيل أوامر Python يدوياً؛ إذ يكفي تشغيل البرنامج ليبدأ الخادم المحلي تلقائياً ويفتح النظام في متصفح الإنترنت الافتراضي.

---

🚀 تشغيل النظام بضغطة واحدة – Windows

تم تجهيز النظام ليعمل كتطبيق قابل للتشغيل على أجهزة Windows.

لا يحتاج المستخدم النهائي إلى تثبيت Python أو Flask أو إعداد بيئة برمجية يدوياً عند استخدام النسخة المجهزة.

طريقة التشغيل

1. قم بتثبيت البرنامج باستخدام ملف التثبيت "ChadCivilRegistry-Setup.exe".
2. بعد التثبيت، افتح البرنامج من اختصار سطح المكتب أو قائمة Start.
3. يبدأ النظام تلقائياً بتشغيل خادم التطبيق المحلي.
4. يفتح النظام في متصفح الإنترنت الافتراضي.
5. يمكنك البدء باستخدام النظام من المتصفح.

عنوان النظام المحلي:

http://127.0.0.1:5000/

كيف يعمل التشغيل؟

عند تشغيل البرنامج:

- يبدأ التطبيق خادم Flask تلقائياً.
- ينتظر البرنامج حتى يصبح الخادم جاهزاً.
- يفتح عنوان النظام في المتصفح الافتراضي.
- يستمر التطبيق في العمل محلياً لتقديم خدماته من خلال المتصفح.

«ملاحظة: البرنامج لا يعمل كنافذة متصفح مستقلة، بل يشغّل خادم التطبيق محلياً ويفتح واجهته في المتصفح الافتراضي.»

متطلبات تشغيل نسخة Windows

- نظام Windows 64-bit.
- متصفح إنترنت حديث.
- مساحة تخزين كافية لملفات البرنامج والبيانات.

لا يحتاج المستخدم إلى تثبيت Python بصورة منفصلة عند استخدام النسخة المجهزة.

حزم التوزيع

يدعم المشروع تجهيز نسخ Windows من خلال:

الملف| الوظيفة
"ChadCivilRegistry-Setup.exe"| تثبيت البرنامج وإنشاء اختصارات التشغيل
"ChadCivilRegistry-Windows.zip"| نسخة البرنامج المجهزة مع ملفات التشغيل المساعدة

👨‍💻 تشغيل المشروع للمطورين

هذا القسم مخصص للمطورين الذين يريدون تشغيل الكود المصدري وتعديله، وليس للمستخدم النهائي الذي يستخدم نسخة Windows المجهزة.

1. استنساخ المشروع

git clone https://github.com/Wusa01/Chad_Civil_Registry.git

cd Chad_Civil_Registry

2. إنشاء بيئة افتراضية

python3 -m venv .venv

تفعيلها على Linux:

source .venv/bin/activate

وعلى Windows:

.venv\Scripts\activate

3. تثبيت المتطلبات

pip install --upgrade pip

pip install -r requirements.txt

4. إعداد متغيرات البيئة

cp .env.example .env

مثال:

SECRET_KEY=change-this-secret-key
DATABASE_URL=sqlite:///civil_registry.db

يجب استخدام قيم سرية قوية وعدم رفع ملف ".env" الحقيقي إلى GitHub.

5. تشغيل التطبيق

python run.py

بعد التشغيل يمكن الوصول إلى التطبيق عبر:

http://127.0.0.1:5000/

«تشغيل الكود المصدري يختلف عن تشغيل نسخة Windows المجهزة بضغطة واحدة.»

🗄️ قاعدة البيانات

يستخدم النظام SQLAlchemy للتعامل مع قاعدة البيانات، وتستخدم SQLite في بيئة التطوير الحالية.

ملف قاعدة البيانات يكون عادةً ضمن:

instance/

يستخدم المشروع كذلك Flask-Migrate وAlembic لإدارة تغييرات بنية قاعدة البيانات.

Database Migrations

إنشاء Migration:

flask db migrate -m "describe changes"

تطبيق Migration:

flask db upgrade

الرجوع إلى Migration سابقة:

flask db downgrade

«يجب أخذ نسخة احتياطية قبل تنفيذ تغييرات قاعدة البيانات، خصوصاً في بيئة الإنتاج.»

أداة إصلاح قاعدة البيانات

يحتوي المشروع على:

fix_db.py

وهو سكربت مساعد لإجراء بعض التعديلات على قواعد بيانات SQLite القديمة، وليس بديلاً عن نظام migrations المنظم.

🔐 توصيات ما قبل الإنتاج

المشروع في مرحلة التطوير، ولذلك لا ينبغي اعتباره جاهزاً للاستخدام الرسمي واسع النطاق قبل إجراء الاختبارات والمراجعات اللازمة.

4. استخدام WSGI Server مثل Gunicorn في بيئات Linux.
5. الانتقال إلى PostgreSQL عند الحاجة إلى بيئة إنتاج متعددة المستخدمين.
6. تأمين قاعدة البيانات والملفات.
7. تشفير النسخ الاحتياطية.
8. اختبار استعادة النسخ الاحتياطية.
9. مراجعة الصلاحيات والتحكم في الوصول.
10. مراجعة رفع الملفات والوثائق.
11. مراجعة آلية التحقق من QR.
12. مراجعة سجلات العمليات والأمان.
13. إجراء اختبارات أمنية ووظيفية شاملة.

ملاحظة حول الوصول من الشبكة: النسخة الحالية التي تعمل على "127.0.0.1" مخصصة للوصول المحلي من الجهاز نفسه. إتاحة النظام لأجهزة أخرى عبر شبكة LAN تحتاج إلى إعدادات تشغيل وشبكة مناسبة، ولا تعني ميزة التشغيل بضغطة واحدة أن النظام أصبح متاحاً عبر الإنترنت.

⚠️ حالة المشروع

المشروع في مرحلة التطوير النشط، ويحتوي على وظائف لإدارة الوقائع المدنية والوثائق والمستخدمين، بالإضافة إلى نسخة Windows قابلة للتشغيل المباشر.

يجب اعتبار المشروع نموذجاً تقنياً قابلاً للتطوير والاختبار والتوسع، وليس نظاماً حكومياً معتمداً أو منظومة وطنية مطبقة حالياً.

تظل بعض الجوانب بحاجة إلى مراجعة واختبار قبل أي استخدام رسمي، خصوصاً:

- البنية الأمنية.
- قاعدة البيانات.
- نظام الصلاحيات.
- النسخ الاحتياطي.
- النشر والتشغيل.
- الاختبارات.
- حماية البيانات المدنية الحساسة.
