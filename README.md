# 🇹🇩 Chad Civil Registry

نظام رقمي لإدارة السجل المدني في تشاد، مبني باستخدام **Python وFlask**، ويهدف إلى تنظيم وإدارة بيانات المواطنين ووثائق الأحوال المدنية بطريقة آمنة وقابلة للتوسع.

يدعم النظام إدارة **المواليد، الزواج، الوفاة، الطلاق**، بالإضافة إلى طلبات المواطنين، إصدار الوثائق، التحقق منها باستخدام QR Code، الأرشفة الرقمية، التقارير، النسخ الاحتياطي، وإدارة المستخدمين والصلاحيات.

---

## 📌 نظرة عامة

**Chad Civil Registry** هو تطبيق ويب لإدارة عمليات السجل المدني، مصمم ليكون قابلًا للاستخدام من قبل:

* 👨‍💼 موظفي السجل المدني
* 🏢 مراكز ومكاتب الحالة المدنية
* 👨‍💻 مديري النظام
* 👤 المواطنين
* 🏛️ مسؤولي المناطق والإدارات

يهدف النظام إلى الانتقال من الإجراءات الورقية التقليدية إلى نظام رقمي يساعد على:

* تنظيم سجلات المواطنين.
* تسهيل إصدار الوثائق.
* تقليل الأخطاء اليدوية.
* توفير إمكانية التحقق من صحة الوثائق.
* حفظ الوثائق إلكترونيًا.
* توفير التقارير والإحصائيات.
* إدارة صلاحيات المستخدمين.
* إنشاء نسخ احتياطية للبيانات.
* دعم اللغة العربية والفرنسية.

# 👥 المستخدمون والصلاحيات

يدعم النظام عدة أدوار للمستخدمين.

### `admin`

مدير النظام، ويمكنه إدارة النظام والمستخدمين والبيانات والصلاحيات.

### `region_mgr`

مسؤول إقليمي يمكنه إدارة ومتابعة العمليات ضمن نطاقه.

### `officer`

موظف سجل مدني يقوم بإدخال ومعالجة السجلات والطلبات.

### `citizen`

مستخدم مواطن يمكنه الوصول إلى الخدمات المخصصة للمواطنين.

> تعتمد الصلاحيات الفعلية على منطق التطبيق والـ routes الموجودة في النظام.

# 🔄 Database Migrations

يستخدم المشروع:

```text
Flask-Migrate
Alembic
```

لإدارة تغييرات Schema قاعدة البيانات.

الأوامر الأساسية:

```bash
flask db init
```

إنشاء Migration:

```bash
flask db migrate -m "describe changes"
```

تطبيق Migration:

```bash
flask db upgrade
```

الرجوع إلى Migration سابقة:

```bash
flask db downgrade
```

> استخدم migrations بعناية، خصوصًا في بيئة الإنتاج، وبعد أخذ نسخة احتياطية من قاعدة البيانات.

# 🐛 Troubleshooting

## المشكلة: ModuleNotFoundError

تأكد من تفعيل البيئة الافتراضية:

```bash
source .venv/bin/activate
```

ثم:

```bash
pip install -r requirements.txt
```

## المشكلة: قاعدة البيانات لا تعمل

تحقق من وجود:

```text
instance/
```

وتحقق من إعدادات:

```text
DATABASE_URL
```

داخل:

```text
.env
```

---

## المشكلة: تغييرات قاعدة البيانات لا تظهر

استخدم migrations:

```bash
flask db migrate -m "update database"
flask db upgrade
```

ولا تعتمد على:

```python
db.create_all()
```

لتحديث الجداول الموجودة.

## المشكلة: PDF باللغة العربية يظهر بشكل غير صحيح

# 🔐 توصيات الإنتاج

من أهمها:

لا تستخدم مفتاحًا بسيطًا أو معروفًا.

استخدم قيمة عشوائية قوية.

### 2. عدم استخدام Debug

في Production يجب ألا يعمل التطبيق باستخدام:

```python

```

يفضل تشغيل Flask خلف WSGI server مثل:

```text
Gunicorn
```

مع:

```text
Nginx
```

أو بيئة تشغيل إنتاجية مكافئة.

### 4. HTTPS

* كلمات المرور.

* رموز التحقق.

### 5. حماية قاعدة البيانات

يجب:

* منع الوصول المباشر لملف قاعدة البيانات.
* إنشاء نسخ احتياطية.

* اختبار استعادة النسخ الاحتياطية.

### 6. حماية حسابات الإدارة
