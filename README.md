## 🚀 تثبيت النظام وتشغيله

### الخطوة 1 — تثبيت المكتبات

```bash
pip install -r requirements.txt
```

أو يدوياً في Termux:

```bash
pip install flask flask-sqlalchemy flask-login flask-migrate \
            flask-bcrypt flask-wtf qrcode pillow reportlab python-dotenv
```

### الخطوة 2 — تشغيل البرنامج

```bash
python run.py
```

### الخطوة 3 — فتح المتصفح

```
http://127.0.0.1:5000
```

سيتم توجيهك تلقائياً لصفحة تسجيل الدخول.

## 👤 إنشاء المدير الأول

عند أول تشغيل قاعدة البيانات تكون فارغة، شغّل هذا الأمر في terminal منفصل:

```bash
python -c "
from app import create_app, db
from app.models.user import User
app = create_app()
with app.app_context():
    u = User(username='admin', full_name='المدير', role='admin', is_active=True)
    u.set_password('admin123')
    db.session.add(u)
    db.session.commit()
    print('✅ تم إنشاء المدير بنجاح')
"
```

ثم سجّل الدخول بـ:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`

> ⚠️ غيّر كلمة المرور فور الدخول من: الملف الشخصي ← تغيير كلمة المرور

## 🔑 دليل المدير (Admin)

المدير يملك كامل الصلاحيات في النظام.

### الأدوار المتاحة

| الدور | الوصف |
|-------|-------|
| `admin` | كامل الصلاحيات |
| `region_mgr` | إدارة مراكز منطقته + التقارير |
| `officer` | تسجيل وعرض سجلات مركزه فقط |
| `citizen` | التحقق من الوثائق وتقديم الطلبات |

---

### 1️⃣ إدارة المستخدمين

**المسار:** القائمة العلوية ← الإدارة ← المستخدمون

#### إضافة موظف جديد
1. اضغط **«إضافة مستخدم»**
2. أدخل: اسم المستخدم، الاسم الكامل، كلمة المرور
3. حدد **الدور** (officer / region_mgr / admin)
4. حدد **المركز** المرتبط به (إلزامي للموظفين)
5. اضغط **«حفظ»**

#### تعديل / تعليق مستخدم
- اضغط على اسم المستخدم لتعديل بياناته
- اضغط زر التبديل لتفعيل أو تعليق الحساب
- من صفحة التعديل يمكن إعادة تعيين كلمة المرور

---

### 2️⃣ إدارة المراكز

**المسار:** الإدارة ← المراكز

#### إضافة مركز جديد
1. اضغط **«إضافة مركز»**
2. أدخل:
   - الاسم بالعربية والفرنسية
   - المنطقة والقسم
   - **الرمز** (مثال: `NDJ001`) — يُستخدم في ترقيم الشهادات، لا يمكن تعديله لاحقاً
3. اضغط **«حفظ»**

> ⚠️ اختر رمز المركز بعناية — يظهر في كل شهادة تُصدَر من هذا المركز

---

### 3️⃣ سجل العمليات (Audit Log)

**المسار:** الإدارة ← سجل العمليات

يعرض جميع العمليات مع:
- اسم المستخدم وعنوان IP
- نوع العملية: `CREATE` / `UPDATE` / `LOGIN` / `LOGOUT` / `EXPORT` / `VERIFY`
- الجدول المُعدَّل والسجل المُتأثر
- التوقيت الدقيق

يمكن التصفية حسب نوع العملية أو الجدول.

---

### 4️⃣ التقارير الإحصائية

**المسار:** القائمة العلوية ← التقارير

- إجمالي المواليد والزيجات والوفيات للسنة المحددة
- توزيع شهري على مدار السنة
- توزيع جغرافي حسب المراكز (أعلى 10 مراكز)
- يمكن تصفية التقارير حسب السنة

---

### 5️⃣ إلغاء الوثائق

**المسار:** الوثائق ← ابحث عن الوثيقة ← اضغط «إلغاء»

- الوثيقة الملغاة تُظهر عند التحقق منها: **«ملغاة / غير صالحة»**
- لا يمكن حذف الوثائق نهائياً — فقط إلغاؤها للحفاظ على سجل المراجعة

## 📝 دليل الموظف (Officer)

الموظف يرى ويُسجّل فقط سجلات **مركزه المرتبط به**.

---

### 1️⃣ تسجيل مولود جديد

**المسار:** المواليد ← إضافة

| الحقل | الإلزامية |
|-------|-----------|
| تاريخ التسجيل | ✅ إلزامي |
| اسم المولود الكامل | ✅ إلزامي |
| الجنس (ذكر / أنثى) | ✅ إلزامي |
| تاريخ الولادة | ✅ إلزامي |
| مكان الولادة | ✅ إلزامي |
| اسم الأب الكامل | ✅ إلزامي |
| مهنة الأب | ✅ إلزامي |
| اسم الأم الكامل | ✅ إلزامي |
| مهنة الأم | ✅ إلزامي |
| ضابط الحالة المدنية | ✅ إلزامي |
| تاريخ / مكان ميلاد الأب أو الأم | ⚪ اختياري |
| ملاحظات | ⚪ اختياري |

بعد الحفظ يُولَّد تلقائياً:
- رقم شهادة فريد (مثال: `BIRTH-2026-NDJ001-00042`)
- رمز QR مرتبط برابط التحقق

---

### 2️⃣ تسجيل عقد زواج

**المسار:** الزواج ← إضافة

**بيانات العقد:**
- تاريخ الزواج ومكانه
- نوع الزواج: أحادي أو تعدد زوجات
- المهر (اختياري): ذكر وجوده والمبلغ
- إعفاء من السن (إن وجد)

**بيانات الزوج والزوجة (لكل منهما):**
- الاسم الكامل، تاريخ ومكان الميلاد
- المهنة، الجنسية، رقم بطاقة الهوية
- اسم الأب واسم الأم

**الشهود:**
- اسم ورقم هوية الشاهد الأول والثاني

**ضابط الحالة المدنية:** اسم الموقّع على العقد

---

### 3️⃣ تسجيل وفاة

**المسار:** الوفيات ← إضافة

**بيانات المتوفى:**
- الاسم الكامل والجنس
- العمر عند الوفاة (أو تاريخ الميلاد إن عُرف)
- محل الإقامة المعتاد

**بيانات الوفاة:**
- تاريخ الوفاة ومكانه
- نوع المكان: مستشفى / منزل / مكان آخر
- سبب الوفاة

**التوثيق:**
- اسم المُشهِد: طبيب / أحد أفراد الأسرة / موظف صحي
- ربط بسجل الميلاد في النظام (اختياري)
- ضابط الحالة المدنية

---

### 4️⃣ البحث والتعديل

- في كل قائمة يوجد حقل بحث بالاسم أو رقم الشهادة
- اضغط على أي سجل لعرض تفاصيله الكاملة
- من صفحة التفاصيل: اضغط **«تعديل»** لتحديث البيانات

---

### 5️⃣ تصدير PDF

من صفحة تفاصيل أي سجل، اضغط **«تصدير PDF»**

يحتوي الـ PDF على:
- ترويسة جمهورية تشاد ووزارة الإدارة المحلية
- شريط ألوان العلم التشادي (أزرق / أصفر / أحمر)
- جميع بيانات الوثيقة
- رمز QR للتحقق الإلكتروني
- حقل توقيع ضابط الحالة المدنية

---

### 6️⃣ تغيير اللغة

في شريط التنقل العلوي:
- اضغط **`AR`** للعربية (RTL)
- اضغط **`FR`** للفرنسية (LTR)

## 🌐 دليل المواطن (Citizen)

بوابة المواطن متاحة للجميع **بدون تسجيل دخول** على:

```
http://127.0.0.1:5000/citizen
```

---

### 1️⃣ التحقق من وثيقة

#### الطريقة الأولى — مسح رمز QR (الأسرع)
1. افتح تطبيق الكاميرا أو قارئ QR على هاتفك
2. صوّب على رمز QR في أسفل الوثيقة المطبوعة
3. سيفتح رابط التحقق تلقائياً
4. تظهر النتيجة فوراً: ✅ **صالحة** أو ❌ **ملغاة**

#### الطريقة الثانية — إدخال الرمز يدوياً
1. افتح: `http://127.0.0.1:5000/citizen`
2. اضغط **«تحقق من وثيقة»**
3. أدخل رمز QR المكتوب في الوثيقة (16 حرفاً)
4. اضغط **«تحقق»**

**معلومات تظهر عند التحقق الناجح:**
- نوع الوثيقة (ميلاد / زواج / وفاة)
- اسم صاحب الوثيقة
- تاريخ الإصدار
- مركز الحالة المدنية المُصدِر
- حالة الوثيقة (صالحة / ملغاة)

---

### 2️⃣ تتبع طلب

1. من بوابة المواطن اضغط **«تتبع طلب»**
2. أدخل رقم الشهادة كاملاً

**أمثلة على أرقام الشهادات:**
```
BIRTH-2026-NDJ001-00001
MARIAGE-2026-NDJ001-00001
DECES-2026-NDJ001-00001
```

---

### 3️⃣ تقديم طلب وثيقة

1. من بوابة المواطن اضغط **«طلب وثيقة»**
2. اختر نوع الوثيقة المطلوبة
3. أدخل بياناتك ومعلومات الاتصال
4. أرسل الطلب — يُعالَج من قِبَل الموظف المختص

## 🔢 نظام ترقيم الشهادات

يُولِّد النظام رقماً فريداً تلقائياً لكل وثيقة بالصيغة:

```
[النوع] - [السنة] - [رمز المركز] - [التسلسل]
```

| النوع | مثال |
|-------|------|
| شهادة ميلاد | `BIRTH-2026-NDJ001-00042` |
| عقد زواج | `MARIAGE-2026-ABJ002-00007` |
| شهادة وفاة | `DECES-2026-NDJ001-00015` |

---

## 🛠️ حل المشاكل الشائعة

| المشكلة | الحل |
|---------|------|
| لا يُقبَل اسم المستخدم أو كلمة المرور | شغّل أمر إنشاء المدير في القسم [إنشاء المدير الأول](#-إنشاء-المدير-الأول) |
| `ModuleNotFoundError` عند التشغيل | شغّل: `pip install -r requirements.txt` |
| الصفحة لا تفتح في المتصفح | تأكد أن البرنامج يعمل، ثم افتح: `http://127.0.0.1:5000` |
| PDF لا يُصدَّر | `pip install reportlab qrcode pillow` |
| لا يمكن رؤية سجلات مراكز أخرى | الموظف يرى مركزه فقط — استخدم حساب `admin` لرؤية الكل |
| خطأ في قاعدة البيانات | احذف ملف `instance/civil_registry.db` وأعد التشغيل |
| تحذيرات SQLAlchemy عند التشغيل | تحذيرات غير مؤثرة، النظام يعمل بشكل طبيعي |

## 🔒 الأمان والصلاحيات

- **كلمات المرور:** مشفرة بـ bcrypt — لا تُخزَّن بشكل واضح
- **التحكم في الوصول:** كل مستخدم يرى فقط بيانات مستواه الوظيفي
- **سجل العمليات:** كل إجراء مسجّل مع اسم المستخدم والوقت وعنوان IP
- **التحقق من الوثائق:** رمز QR فريد لكل وثيقة قابل للإلغاء في أي وقت
